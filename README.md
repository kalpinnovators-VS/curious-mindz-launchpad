# Curious Mindz Launchpad

Create a premium single-page landing page for an AI automation startup called "Curious Mindz".

Act as an award-winning UI/UX designer and senior front-end developer. Create a website that looks like it was designed for a premium startup in 2025, with excellent visual hierarchy, conversion-focused copy, modern animations, and responsive design.

About the business

I provide Robotics and innovation education to the school going children. All the teaching is through live hands-on in-person workshops. I want to create a website for the same. I have below in mind.

Target Audience:

Parents of the school going children of class 4th to 11th. Generally the parents are young, modern, working mostly in IT companies.

Design:

- Modern SaaS style.

- Generally I like light, refreshing colors for the site. But dark is also fine if you think so.

- Smooth animations and glassmorphism effects

- Our tagline is Learn.  Create.. Innovate

Sections:

- Hero section with strong value proposition and CTA

- context / about the course

- About us

- there should be hovering button for contact through WhatsApp. 

- Showcase of the projects created by past students. may be carousal of tiles, each tile with a pic of project + single sentence description. Click on that should open pop-up with details of project.

- Courses offered. Similar to the projects section it should be tiles with small image and offerings of the course beneath.

- How it works (3 steps)

- Parents testimonials

- Pricing plans

- FAQ

- Contact, CTA

	

Technical Requirements:

- Responsive design

- HTML, CSS, JS in one file

- SEO optimized

- Animated statistics counters

- Smooth scrolling navigation

Generate production-ready code.​‌

I have attached my company logo.

Analyze the logo colors, style, and branding characteristics first.

Based on the logo:

- Create a professional color palette that complements the logo.

- Use the logo colors as primary brand colors.

- Suggest suitable secondary, accent, background, and text colors.
